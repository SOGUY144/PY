#  Hand Tracking AR Application

> ควบคุมคอมพิวเตอร์และสร้างสรรค์ผลงานได้ด้วยมือของคุณเอง!

แอปพลิเคชันนี้ใช้เทคโนโลยี MediaPipe สำหรับตรวจจับมือและใบหน้าแบบเรียลไทม์จากกล้องเว็บแคม พร้อมฟีเจอร์มากมายที่จะทำให้คุณได้สัมผัสประสบการณ์ AR ที่น่าตื่นเต้น

---

##  ฟีเจอร์หลัก

###  โหมดการใช้งาน

| โหมด | คีย์ | คำอธิบาย |
|------|------|----------|
| **HUD Mode** | `1` | แสดง visualization ของมือพร้อมวงแหวน HUD สวยๆ รอบฝ่ามือ |
| **Mouse Mode** | `2` | ควบคุมเมาส์ด้วยการเคลื่อนไหวมือ รองรับ click, drag และ scroll |
| **Canvas Mode** | `3` | วาดรูปบนหน้าจอได้อย่างอิสระโดยใช้นิ้วชี้ |
| **3D Mode** | `4` | สัมผัสลูกบาศก์ 3D ที่หมุนได้ตามการเคลื่อนไหวมือ |
| **Face Mode** | `5` | ตรวจจับใบหน้าและวาด HUD รอบใบหน้า |

###  ท่าทางมือ (Gestures)

- **Peace**  — นิ้วชี้และนิ้วกลางยืดออก นิ้วนางและนิ้วก้อยหุบ
- **Fist**  — มือกำทั้งหมด
- **Index Only** — เฉพาะนิ้วชี้ยืด (ใช้สำหรับวาดรูปบน Canvas)

###  เอฟเฟกต์พิเศษ

- **Glow Effects** — เส้นและวงกลมเรืองแสงรอบมือ
- **Background Blur** — ทำให้พื้นหลังเลือนเพื่อเน้นมือ
- **Color Trails** — รอยติดตามสีสันตามการเคลื่อนไหว
- **Smooth Animations** — ภาพเคลื่อนไหวลื่นไหล

##  วิธีติดตั้งและใช้งาน

### 1. ติดตั้ง Dependencies

```bash
pip install -r requirements.txt
```

### 2. ดาวน์โหลดโมเดล MediaPipe

โปรแกรมต้องการไฟล์ `hand_landmarker.task` ซึ่งเป็นโมเดลสำหรับตรวจจับมือ

1. ไปที่ [MediaPipe Hand Landmarker](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker)
2. ดาวน์โหลดโมเดล
3. วางไฟล์ `hand_landmarker.task` ไว้ในโฟลเดอร์เดียวกับ `app.py`

### 3. รันโปรแกรม

```bash
python app.py
```

### 4. ควบคุมโปรแกรม

| ปุ่ม | การทำงาน |
|------|----------|
| `1` - `5` | เปลี่ยนโหมดการทำงาน |
| `M` | เปิด/ปิด Mouse Mode |
| `C` | เปลี่ยนสีพู่กัน (Canvas Mode) |
| `X` | ล้าง Canvas |
| `Q` หรือ `Esc` | ออกจากโปรแกรม |

---

## 🖱️ Mouse Mode — ควบคุมเมาส์ด้วยมือ

เมื่อเปิด Mouse Mode แล้ว คุณสามารถ:

- **เคลื่อนเมาส์** — ขยับมือเพื่อควบคุมเคอร์เซอร์
- **คลิก** — กดนิ้วหัวแม่มือแตะนิ้วชี้
- **ลาก (Drag)** — กดค้างแล้วลากมือ
- **เลื่อนหน้าจอ (Scroll)** — ขยับมือขึ้น-ลง

---

## 🎨 Canvas Mode — วาดรูปด้วยมือ

1. กด `3` เพื่อเข้า Canvas Mode
2. ยกนิ้วชี้ขึ้นเพียงนิ้วเดียว
3. ขยับมือเพื่อวาดรูปบนหน้าจอ
4. กด `C` เพื่อเปลี่ยนสี
5. กด `X` เพื่อล้างรูปที่วาดไว้
